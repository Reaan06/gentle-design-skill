# gentle-design-skill v1.0.0

Professional-grade design quality for the Gentle Shell / Pi design workflow — evidence-backed rules, art-direction catalog, deterministic anti-slop gate.

## What's inside
- `skill/gentle-design-skill/` — SKILL.md + 9 evidence-cited references (token system, 8-direction art catalog + Direction Contract, platform rules for web/mobile/desktop, first-class dark mode, harness architecture, professional pass, anti-generic playbook)
- `scripts/design-gate.py` — deterministic 12-rule static gate (tokens, 4px ramp, `transition: all`, AI-slop tells), `file:line` findings, `--json`, exit 0/1/2
- `examples/` — two fully verified designs: **Pulse** (analytics SaaS: web/mobile/desktop + dark, 86/86 checks) and **Molino** (Editorial-direction roastery)
- `docs/propuesta.pdf` — Spanish pitch document

## Verification
- `design-gate.py` exit 0 on all 7 example artboards
- DESIGN.md lint (`@google/design.md lint`): 0 errors, 0 warnings on both examples
